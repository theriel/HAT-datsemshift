## Dataset Information

### What do the instances in this dataset represent?
Each instance represents a specific relation between a source concept and a target concept as realized in one or more languages. There are 3871 unique instances of semantic shifts. Shifts are categorized by type (e.g., Polysemy, Derivation, Motivation), directionality, and lexical or conceptual attributes.

### Additional Information

This is a derived dataset originating from Zalizniak et al. (2024)'s Database of Semantic Shifts, found at http://datsemshift.ru, using the python code and derived CLDF format from https://github.com/lexibank/datsemshift/tree/v1.1rc. 

The dataset here contains records of semantic shifts observed in 125 Indo-European languages, across 7 different branches: Slavic, Italic, Germanic, Greek, Armenian, and Celtic. The data includes extinct languages as well, such as Latin and Old Church Slavonic. The data can be used to study semantic change, polysemy networks, cross-linguistic patterns, and related phenomena. Possible analytical tasks include classification (e.g., predicting shift type or status) and clustering (grouping similar shifts).
